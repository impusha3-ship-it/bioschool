# Биология 5-9

Сайт-помощник для уроков биологии в 5-9 классах по программе Пасечника («Линия жизни»).

Спецификация: `docs/superpowers/specs/2026-08-07-bio-school-design.md` в родительской папке.

## Разработка

```bash
npm test      # запустить тесты
npm run dev   # локальный сервер на http://localhost:5180
```

Зависимостей нет: тест-раннер встроен в Node 24, сборщик не используется.

## Публикация

Сайт раздаётся GitHub Pages прямо из ветки `main`, сборка не нужна — достаточно `git push`.
